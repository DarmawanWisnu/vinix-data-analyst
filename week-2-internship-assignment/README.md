## 📌 Overview

Minggu kedua program **MSIB Batch 5** di **PT Vinix Seven Aurum (Vinix7)** berfokus pada **Eksplorasi Data Sekunder (Secondary Data Exploration)**. Penugasan ini melatih kemampuan Data Analyst dalam mengidentifikasi, mengaudit, dan menilai kelayakan dataset publik sebelum diolah menjadi wawasan bisnis.

Pada modul ini, analisis dilakukan terhadap dataset publik (`food_coded_dataset1.csv`) untuk memetakan struktur data, mendeteksi inkonsistensi awal, serta merancang kerangka pengolahan data terstruktur.

---

## 🎯 Objectives & Deliverables

- **Literature & Reference Identification:** Melakukan pencarian referensi dan kajian studi pustaka terkait topik dataset sekunder.
- **Secondary Data Auditing:** Menguji integritas data publik, struktur kolom, dan tipe data pada `food_coded_dataset1.csv`.
- **Data Structuring:** Menyusun workbook konsolidasi `Fase_1_Eksplorasi_Data_Sekunder.xlsx` untuk dokumentasi pemetaan fitur.
- **Reporting & Documentation:** Menyusun laporan komprehensif eksplorasi data sekunder pada Google Docs dan pengumpulan resmi pada **15 September 2026**.
